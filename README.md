# Codentra Technologies

Premium digital engineering platform for next-gen digital products.

## Features
- **High-Performance Architecture**: Built with React and Vite for optimal speed.
- **Bespoke UI**: Premium, enterprise-grade design using Vanilla CSS.
- **Dynamic Animations**: Fluid motion system powered by Framer Motion.
- **Responsive Design**: Fully optimized for all device scales.

## Tech Stack
- **Frontend**: React 19, Framer Motion
- **Styling**: Vanilla CSS (Custom Design System)
- **Icons**: React Icons (Feather Icons)
- **Build Tool**: Vite

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Project Structure
- `src/components`: Reusable UI components and layouts.
- `src/sections`: Main website sections (Hero, About, Services, etc.).
- `src/data`: Centralized site configuration and content data.
- `src/assets`: Project images and brand assets.
- `src/App.jsx`: Main application assembly.
